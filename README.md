# NetPulse — AIORI-3 Hackathon

**Problem Statement:** PS-014 — Pilot Internet-Quality Comparison by Verified Access Medium  
**Team:** SYNORA  
**Repository:** A3-PS014-TC169  
**Category:** Smart Cities

## About the Project

NetPulse is a prototype designed to monitor and compare internet connection quality across verified access media, helping users understand network performance over time.

## Problem We Address

Internet quality can vary across access media and over time. Users need a clear way to examine network performance and identify connectivity issues using measurable indicators.

## Proposed Solution

NetPulse provides a dashboard-oriented approach to internet-quality monitoring and comparison. It is designed to collect network measurements, store observations, analyse performance trends, and present results through visualisations.

## Key Metrics

- **Latency:** Time taken for a network response.
- **Packet loss:** Percentage of packets that fail to reach their destination.
- **Throughput:** Rate at which data is successfully transferred, where supported.

## Prototype Components

- **Measurement module:** Collects network-performance observations.
- **Backend API:** Handles measurement data requests.
- **Database:** Stores timestamped observations and related metadata.
- **Dashboard:** Displays measurements and performance trends.
